# 聊天自動回覆實作計畫

**Goal:** 偵測新聊天，AI 回覆後由原位置接續腳本。

**Architecture:** `core/chat_reply_config.py` 管設定；`core/chat_observer.py` 管 OCR 行與上下文；`core/chat_reply.py` 管 AI 與送出；Player 提供動作邊界回呼；GUI 編輯與 RunController 接線沿用現有元件。

**Tech Stack:** Python 3.11+、NumPy/OpenCV、既有 PaddleOCR／ChatProvider、PySide6。無新增依賴。

**Spec:** `docs/superpowers/specs/2026-09-30-chat-auto-reply-design.md`

## 約束

- 保留工作目錄中原有未提交變更；不整批提交或重設。
- 核心不依賴 Qt；實際輸入只發生在播放器執行緒。
- 外部 AI 的背景工作僅產生資料，停止或逾時後不能送出。
- 先寫行為測試、確認失敗，再實作並驗證。

## 工作項目

- [x] 設定與播放器：`ChatReplyConfig` 存入 `ScriptSettings.chat_reply`；`Player(..., on_action_boundary=None)` 在每個動作前呼叫並再次檢查停止。用巢狀腳本的按鍵序列證明不重跑；未接服務時拒絕啟用設定。
- [x] 聊天觀察：`ChatObserver.observe(image, boxes)` 回傳新的候選訊息，並保留 `history`；字色從 OCR 框內取樣，合併同行文字；第一次僅建立基準。測試綠白字、其他色、自己、畫面捲動與重複內容。
- [x] 回覆服務：`ChatReplySession(platform, config, provider, stop_event, on_progress)` 可當動作邊界回呼。驗證 ID／單行文字，依訊息的頻道套用設定操作。測試上下文傳送、路由、停止、失敗與逾時。
