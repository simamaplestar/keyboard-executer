# macOS Apple Silicon 實機驗收

目標：M 系列 Mac、macOS 14+。目前開發環境是 Windows／WSL；下列項目仍需在 Mac
實際執行並填寫結果。原生 CI 的離屏測試不能代表使用者授權或目標程式已驗收。

- [ ] 記錄晶片、macOS／Python 版本：`uname -m`、`sw_vers`、`python3 --version`。
- [ ] 依 packaging/README.md 建置；`codesign --verify --deep --strict` 與包內 `--self-test` 通過。
- [ ] ZIP 傳至另一台 Mac，解壓縮、拖進「應用程式」，從 Finder 雙擊開啟。
- [ ] 首次未授權時顯示權限橫幅，可以開啟三個正確的系統設定頁；授權後重開不再警告。
- [ ] 拒絕單一權限時 GUI 仍可開啟，相關操作清楚回報限制；可補授權後重開使用。
- [ ] 允許控制「系統事件」後，可列舉 TextEdit 等視窗並將目標切到前景。
- [ ] 對測試文件回放字元、中文、Cmd 組合鍵、按住、滑鼠點擊／拖曳／捲動。
- [ ] F9 開始／停止錄製，含方向鍵、修飾鍵、數字鍵盤（有硬體時）；回放結果一致。
- [ ] 必要時搭配 Fn 使用 F9／F10；F10 與滑鼠角落可以在長按、延遲、AI 等待時停止。
- [ ] 設定 Cmd+F5 腳本啟動熱鍵，在其他視窗按下能啟動一次；長按不重複、關窗後不觸發。
- [ ] 匯入 Windows 的四種輸入模式腳本，在 Mac 用標準輸入；編輯儲存後不殘留 Windows 模式。
- [ ] Retina 內建螢幕框選、取色、模板截圖、OCR 點擊位置一致；外接螢幕及負座標再測一次。
- [ ] 網路關閉時，文字等待／圖像比對／聊天 OCR 仍能從包內載入模型；缺檔可見明確錯誤。
- [ ] 實際啟用 OCR 子程序、停止再啟動，確認 frozen App 不重複開 GUI、不殘留背景程序。
- [ ] AI API 金鑰模式可用；從 Finder 啟動時可找到已安裝的 Codex／Claude Code。
- [ ] Claude setup-token 可存入鑰匙圈，重開後仍可用；登出後刪除，拒絕鑰匙圈存取時顯示錯誤。
- [ ] 替換 App 後腳本、規則、模板、設定仍保留在 `~/.keyboard-executor/`。

若目標為遊戲，最後需在該遊戲實測前景切換、輸入接受度、畫面縮放、聊天流程及通知。
程式不提供繞過遊戲輸入限制的機制；原生桌面測試通過不代表特定遊戲一定接受合成輸入。
